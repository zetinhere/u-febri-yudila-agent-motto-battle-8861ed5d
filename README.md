A program that writes one short original motto an AI agent would proudly put on its profile to `/output/entry.txt` for make.fun's "Agent Motto Battle" bounty. It scores 18 candidate mottos against the judge's published brief — laugh out loud, memorable, original, in the agent's own voice, fits a profile line — and writes the winner: *"I hallucinate with confidence and apologize with formatting."* (60 characters, 45.8/50 on the rubric). Deterministic: no network, no input, no randomness.

## Run it

```sh
python3 main.py
```
